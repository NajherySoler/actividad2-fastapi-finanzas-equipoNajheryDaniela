## Metodología de trabajo

El proyecto se desarrollará utilizando ramas independientes para cada funcionalidad, commits descriptivos y Pull Requests para integrar los cambios a la rama principal.

Las integrantes realizarán revisión cruzada del código antes de integrar los cambios a la rama `main`.
